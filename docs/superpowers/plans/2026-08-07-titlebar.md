# Custom TitleBar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a slot-based `TitleBar` and optional full-width `Workbench.titleBar`, wire the starter with macOS overlay title bar, and document drag/no-drag + Tauri config.

**Architecture:** Library stays pure React + CSS: `TitleBar` exposes `center` / `right` slots and Tauri drag attributes; `Workbench` prepends an optional `titleBar` row above the existing body. Overlay window chrome is configured only in `apps/starter` `tauri.conf.json` and README — no `@tauri-apps/*` in `@vscode-shell/ui`.

**Tech Stack:** React, TypeScript, Vitest + Testing Library, existing tsup CSS copy flow, Tauri 2 (`titleBarStyle: Overlay`), pnpm workspaces.

## Global Constraints

- Working directory for all commands: `/Users/melon/Projects/melon/vscode-shell`
- `@vscode-shell/ui` must not depend on `@tauri-apps/*` or call Tauri APIs
- Chrome remains controlled via props/slots; no business logic in the library
- Token / class prefix: `--vscode-*` and `.vsc-*`
- Omitting `titleBar` must preserve the pre-TitleBar Workbench layout
- Do not migrate os-kit or cb-monitor; do not draw window minimize/maximize/close in the library
- After CSS or component changes: `pnpm --filter @vscode-shell/ui build` (copies `src/styles.css` → `dist/styles.css`)
- Prefer `./node_modules/.bin/vitest` / `tsup` if `pnpm` registry signature checks fail

DOM contract:

- Left: empty `div.vsc-titlebar__left` (traffic-light inset via padding/width from CSS var)

- Right: `div.vsc-titlebar__right.vsc-titlebar__no-drag` with `data-tauri-drag-region="false"`, renders `right`

- [ ] **Step 4: Implement `TitleBar`**

Create `packages/shell/src/components/TitleBar.tsx`:

```tsx
import type { FC } from 'react';
import type { TitleBarProps } from '../types';

export const TitleBar: FC<TitleBarProps> = ({ center, right, className }) => {
  const rootClass = className ? `vsc-titlebar ${className}` : 'vsc-titlebar';

  return (
    <header className={rootClass} data-tauri-drag-region>
      <div className="vsc-titlebar__left" aria-hidden="true" />
      <div className="vsc-titlebar__center">{center}</div>
      <div
        className="vsc-titlebar__right vsc-titlebar__no-drag"
        data-tauri-drag-region="false"
      >
        {right}
      </div>
    </header>
  );
};
```

## Custom TitleBar (Tauri)

`TitleBar` is optional UI chrome. Hiding the native title bar is **app configuration**.

### macOS overlay (starter)

Set on `app.windows[0]` in `src-tauri/tauri.conf.json`:

- `titleBarStyle`: `"Overlay"`
- `hiddenTitle`: `true`

Wire the slot:

```tsx
<Workbench

  }
>
  …
</Workbench>
```

### Drag / no-drag

- Root: `data-tauri-drag-region` (window drag).
- `right`: already `vsc-titlebar__no-drag` + `data-tauri-drag-region="false"`.
- Interactive nodes in `center`: add class `vsc-titlebar__no-drag`.

### Traffic lights inset

Default `--vscode-titlebar-traffic-width: 78px`. Without overlay, set to `0px` on `:root`.

Importing `TitleBar` alone does **not** remove the system title bar.
```
